# Automation: APK

Перед установкой сервиса необходимо добавить в систему APK репозиторий _HOMEd_, если он еще не был добавлен.

Инструкция по добавлению репозитория находится [здесь](/common/apk/).

## Установка и обновление сервиса

```sh
apk update && apk add homed-automation
```

## Что дальше?

После успешной установки _HOMEd Automation_ можно переходить к [конфигурации](/automation/configuration/).
